# fSpawnerFix [![CodeFactor](https://www.codefactor.io/repository/github/leerdie/fspawnerfix/badge)](https://www.codefactor.io/repository/github/leerdie/fspawnerfix)

Небольшой плагин для Paper, который восстанавливает тип моба в спавнере, установленном из предмета с сохранёнными данными о его состоянии

## Требования

- Java 17
- Maven
- Paper 1.20.1

## Конфигурация

При первом запуске плагин создаст файл `plugins/fSpawnerFix/config.yml` с параметром:

```yaml
debug: false
```

Установите `debug: true`, чтобы включить отладочные сообщения в консоль

Плагин не регистрирует команды и в нём нет разрешений

Скоро обнова!
